# User decisions (append-only)

Only decisions the user actually stated go here. Agent recommendations, proposals and findings do not. Each entry carries the tag of the agent that recorded it (`[claude]`, `[gpt]`, `[deepseek]`). Entries are never deleted or rewritten. A later decision that overrides an earlier one gets a new entry, and the earlier entry gets a trailing "**Superseded YYYY-MM-DD:** see <date> entry" note. Corrections are dated "Correction [tag] YYYY-MM-DD: ..." lines.
